# Submission-stage release scope

This version is a deliberately limited public evaluation package. It contains only generic retrieval-metric code and a data-free smoke example.

The following materials are reserved for the post-acceptance release:

- CORTIVA route encoders and training code
- target-space alignment and candidate-score fusion implementation
- pretrained weights and initialization bundles
- locked full-experiment configurations
- participant-level and query-level source tables
- neural recordings, stimulus images, and third-party model assets
- complete figure-generation and ablation pipelines

This boundary is stated explicitly so that the repository is not mistaken for the complete reproduction package during peer review. The package does not download external data and does not claim to reproduce the manuscript endpoints by itself.
