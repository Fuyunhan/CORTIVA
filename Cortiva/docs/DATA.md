# Data access

No EEG, MEG, stimulus-image, or participant-level result data are bundled in this submission-stage package.

The evaluator operates on a user-supplied square NumPy similarity matrix. The diagonal is treated as the correct query-candidate label. Users are responsible for obtaining any external dataset or feature representation under the terms specified by its original provider.

The complete data-preparation instructions and source tables will accompany the post-acceptance reproduction release.
